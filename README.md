# Hangar

A session manager for [Claude Code](https://claude.com/claude-code) on Windows and Linux. It lists every project you have opened and its sessions, and lets you resume, rename or delete them from one window.

![Projects and their running sessions](docs/screens/projects.png)

## Features

- All your projects and their Claude Code sessions in one list, with search and pinning.
- Resume, rename or delete a session, or start a new one, from a right-click menu.
- Running sessions are marked, with their own CPU and memory, and a double-click raises their terminal window or tab.
- A project file panel: folder tree, or just the files git says changed, with open, rename, move and delete.
- Side pane tabs for Files, Skills and Artifacts.
- Paste a clipboard screenshot into a terminal as a file path.
- PC and Claude usage gauges (CPU, memory, five-hour and weekly limits).
- Dock the window as a reserved band on a screen edge, keeping your desktop icons.
- Side by side or stacked layout, with resizable panes.
- Always-on-top pin.
- Git status on project rows, update from the base branch, and worktrees.
- Updates itself, with a prompt when a new version is out.
- English and Korean.
